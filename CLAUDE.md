# Agent notes

Start at `HANDOFF.md`.

## Docs

- Plan docs (`docs/TODO.md`, `docs/MULTIPLAYER_PLAN.md` and any other plan) hold only open work and the current state. Never write changelogs in them ("Done <date>: …", what a step changed, how it was verified).
- Changelogs go in `docs/IMPLEMENTED.md`. When an item is finished, mark it done in one line in the plan, or remove it, and keep only the parts still open.
